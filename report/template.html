The agent

Composio Instant (Exa) for retrieval, NVIDIA Nemotron 3.5 Lightning for extraction and verification, and deterministic code for the rest. Failed calls retry before a row is sent to manual review.

01 · RETRIEVE

Find + read docs

EXA_SEARCH finds candidate docs and EXA_GET_CONTENTS_ACTION returns clean text. Falls back to DuckDuckGo + trafilatura on failure. Cached in SQLite.

02 · EXTRACT

Structured + gap-fill

Nemotron fills a strict JSON contract (Pydantic) with a retry on failure. Auth aliases are normalized; unresolved failures enter the SQLite manual-review queue. Unknown or low-confidence fields trigger a targeted re-query.

03 · VERIFY

Self-critique

A second pass asks whether the cited evidence actually supports each claim and flags disputed rows as needs-human.

04 · AGGREGATE

Patterns + clusters

pandas computes deterministic counts and segments apps into easy-win / with-work / needs-outreach / blocked — never by the LLM.

Where a human was needed

  • Resolving ambiguous access tiers (free tier + gated endpoints).
  • Apps with no public docs or defunct sites.
  • Confirming whether an MCP actually exists.
  • The hand-checked accuracy sample and rubric fixes.

Why this stays cheap and verifiable

  • Retrieval runs on Composio's free Instant credit; extraction runs through NVIDIA's API.
  • The verification loop carries accuracy and flags disputed rows.
  • DuckDuckGo + trafilatura is an automatic fallback if Composio fails.
  • SQLite stores cached docs, per-app results and a manual-review queue; JSON is updated after each app.
